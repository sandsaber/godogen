# AI Tool Compatibility

Published Godogen repos use `AGENTS.md` as the canonical runtime instruction file and `.agents/skills/` as the canonical skill directory.

The compatibility files below are bootstrap shims. They point common AI tools back to the same canonical runtime instead of maintaining separate instructions per tool.

| Tool | Generated file | Purpose |
|------|----------------|---------|
| Codex and AGENTS-aware tools | `AGENTS.md` | Canonical repository instructions |
| OpenCode | `opencode.jsonc` | Loads `AGENTS.md`, `GODOGEN.md`, and the main `godogen` skill |
| Claude Code | `CLAUDE.md` | Imports `AGENTS.md` |
| Gemini CLI | `GEMINI.md` | Imports `AGENTS.md` |
| Cursor | `.cursor/rules/godogen.mdc` | Always-applied rule pointing to `AGENTS.md` and `godogen` |
| Cline | `.clinerules/godogen.md` | Rule pointing to `AGENTS.md` and `godogen` |
| Windsurf | `.windsurf/rules/godogen.md` | Rule pointing to `AGENTS.md` and `godogen` |
| Continue | `.continue/rules/godogen.md` | Rule pointing to `AGENTS.md` and `godogen` |
| Generic tools | `GODOGEN.md` | Plain markdown start-here file for tools without a skill protocol |

## Publish Modes

`publish.sh` writes all compatibility shims by default:

```bash
./publish.sh --engine godot --out ~/my-game
```

Use a smaller compatibility set when the target project needs fewer generated files:

```bash
./publish.sh --engine godot --agent-compat minimal --out ~/my-game
./publish.sh --engine godot --agent-compat none --out ~/my-game
```

Modes:

- `full` — `GODOGEN.md`, `opencode.jsonc`, and all tool-specific shims
- `minimal` — only `GODOGEN.md` and `opencode.jsonc`
- `none` — only canonical `AGENTS.md` and `.agents/skills/`

## Existing Project Safety

Generated compatibility files contain a `Generated by godogen publish.sh.` marker. On repeat publish, Godogen updates files with that marker and preserves user-owned files without it.

If a project already has `opencode.json`, Godogen does not create a competing `opencode.jsonc` unless a generated `opencode.jsonc` already exists.

Use dry-run before publishing into a project with existing agent configuration:

```bash
./publish.sh --engine godot --merge --dry-run --out ~/existing-project
```
