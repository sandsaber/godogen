# Godogen Godot Runtime

Use godogen to generate or update this Godot game from a natural-language description.

If this AI tool supports repository skills, invoke the `godogen` skill. Otherwise, read `.agents/skills/godogen/SKILL.md` first and follow its staged pipeline from there.

For targeted Godot class APIs, C# Godot syntax, or GDScript syntax, use the `godot-api` skill when available. Otherwise, read `.agents/skills/godot-api/SKILL.md` and follow its lookup workflow.

Keep durable run state in `PLAN.md`, `STRUCTURE.md`, `ASSETS.md`, and `MEMORY.md` so any agent can resume from files instead of conversation history.
